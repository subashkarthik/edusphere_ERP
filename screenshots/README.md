# EduSphere LMS Screenshots

This directory stores visual walkthroughs of the 5 LMS Pillars and Role-Based Dashboards:

1. `01_login_roles.png` — Multi-role authentication & registration with secure role gating.
2. `02_student_dashboard.png` — Student Intelligence Workspace with real-time course cards, attendance percentage, and assessment tracker.
3. `03_faculty_dashboard.png` — Faculty Operational Hub showing assigned courses, enrolled students, pending grading, and today's sessions.
4. `04_admin_dashboard.png` — University Administration Hub with live user metrics, active curricula, campus attendance rate, and audit trails.
5. `05_course_catalog_enrollment.png` — Self-enrollment catalog and faculty curriculum management.
6. `06_attendance_ledger.png` — Faculty attendance marking modal & student attendance status with <75% warning indicator.
7. `07_assessments_quizzes.png` — Faculty MCQ quiz creator, student quiz runner with countdown timer, and automated scoring.
8. `08_assessments_assignments.png` — Student submission uploader and single-modal faculty rubric grading.
9. `09_certificate_generation.png` — 3-criterion eligibility verification (Attendance ≥75%, Assessments ≥50%, Progress = 100%) and ReportLab QR-coded PDF certificate.
10. `10_public_certificate_verification.png` — Public verification portal validating certificate codes and cryptographic authenticity.
